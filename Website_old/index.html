⚙️ How It Works

From API Call to WhatsApp Delivery in Under 300ms

Our engine handles the entire ZATCA compliance pipeline automatically.

1
Step 1 — API Call

Send JSON Payload

Your ERP or system sends a single POST request to /api/v1/invoices/zatca-whatsapp with invoice data in JSON format. That's all you need to do.

JSON 
POST /api/v1/invoices/zatca-whatsapp
{
  "seller": { "name": "Tech Solutions", "vat": "300..." },
  "items": [{ "name": "IT Consulting", "qty": 10, "vat": 15 }],
  "whatsapp": { "to": "+966XXXXXXXXX" }
}
2
Step 2 — ZATCA Engine

Cryptographic Processing

Our engine automatically generates UBL 2.1 XML, computes SHA-256 hash, chains it with previous invoices, and applies ECDSA secp256k1 digital signature with your CSID.

3
Step 3 — Clearance

ZATCA Portal Integration

B2B Standard Invoices get real-time mTLS clearance via FATOORA Portal. B2C Simplified Invoices are queued for async 24h batch reporting. Failed attempts go to DLQ with automatic retry.

4
Step 4 — PDF & QR

Document Generation

System generates PDF/A-3 with embedded XML and Base64 TLV QR Code containing Seller Name, VAT Number, Timestamp, Total, VAT Amount, Hash, and ECDSA Signature.

5
Step 5 — Delivery

WhatsApp Delivery

Meta WhatsApp Cloud API sends bilingual Arabic/English invoice template with PDF attachment and Click-to-Pay button (Moyasar/PayTabs). Real-time delivery tracking: SENT → DELIVERED → READ.
