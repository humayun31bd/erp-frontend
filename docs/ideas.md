### 3. Backend Logic (Website-e kivabe showcase korben)

Website-e B2B buyer-der trust build korar jonno "How it Works" section-ta khub transparent hote hobe. Nicher sequence-ta website-er ekta interactive section hisabe use korte paren:

1. **1. Service Completion & Data Entry:** User Dashboard.
Service company tader service details (item, VAT 15%, buyer CRN) system-e input dibe aur "Generate Invoice" click korbe.


2. **2. ZATCA Phase 2 Cryptographic Clearance:** API Backend.
Apnar ZATCA engine automatically XML hash create korbe, FATOORA portal-er sathe API diye communicate kore clearance/reporting complete korbe.


3. **3. QR Code & PDF Generation:** Compliance.
ZATCA theke verified response asar por system automatically Base64 Encoded QR Code (Phase 2 compliant) shoho ekta standard Arabic/English PDF invoice generate korbe.


4. **4. WhatsApp Middleware Delivery:** Automation.
WhatsApp Cloud API ba apnar custom middleware use kore, oi PDF aur ekta Mada/STC Pay payment link directly client-er WhatsApp number-e chole jabe.
